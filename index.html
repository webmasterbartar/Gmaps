🗺️ استخراج کسب‌وکارهای پیچ و مهره

جستجو برای هر شهر به صورت مرحله‌ای انجام می‌شود. پیش‌فرض، مراکز ۳۱ استان است؛ برای تمام شهرهای ایران باید فهرست کامل را جایگزین کنید.

این نسخه از Google Places API استفاده می‌کند و به کلید فعال با Billing نیاز دارد. ممکن است هزینه مصرف API داشته باشد. هر شهر حداکثر ۶۰ نتیجه و کلید API فقط در تنظیمات سرور نگهداری می‌شود.
